# 所作シミュレーター（仮題）

日本の儀式・作法・慣習 200 項目（S001〜S200）を、写実寄りの 3D で「ちゃんとしようとして、失敗して、それでも場を成り立たせる」ゲームにする試作です。

- いま遊べるのは **第一章「親への結婚挨拶」（場面A）** です。玄関から帰りの見送りまで 8 か所あります。
- 場面B「名刺交換」と場面C「神社参拝」は、台帳と仕様だけできています。まだ遊べません。
- 人物は、顔・髪・服のある写実の人の 3D モデル（Microsoft Rocketbox、MIT）に替えました。まばたき・口・目線・指も動きます。
- **操作は「押すだけ」になりました（2026-11-28）。** Space かクリック（スマホは右下の「押す」）ひとつで、ゲージの金色をねらって押す・ためてはなす・くり返し押す、の3つだけで遊べます。前のマウスとキーを使い分ける操作は、設定の「こだわり」で選べます。
- **スマホでも遊べます**（横向き）。
- 音・家具・お辞儀や正座の動きは、まだ **仮の素材** です。完成見本の段階ではありません（`docs/assets.md`）。
- **人による試遊はまだしていません。** 通しで確かめたのは、自動で操作する台本（押すだけ用 `tools/play-bot-easy.mjs`・こだわり用 `tools/play-bot.mjs`・スマホ用 `tools/play-bot-touch.mjs`）だけです（`docs/status.md`）。

## 人物の確認室

人物ひとり（と相手役）を、和室と手土産の箱で実際に動かして確かめる場所です。待機・見る・歩く・止まる・お辞儀・箱を持つ・置く・渡す・最初に戻す、を操作パネルとキーで動かせます。
開き方・操作・確かめた結果は [`docs/lab.md`](docs/lab.md)。手元では http://127.0.0.1:8150/lab.html 、公開ページは https://kensho-goto.github.io/shosa-simulator/lab.html 。

## スマホ・ほかの人に遊んでもらう

公開ページ：https://kensho-goto.github.io/shosa-simulator/ （合言葉：いいんじゃ）

main に取り込むと、公開ページは自動で新しくなります（`.github/workflows/pages.yml`）。合言葉の画面は `src/gate.js` です。この PC で開くとき（127.0.0.1）は合言葉を聞きません。

## 動かし方

必要なもの：Node.js 18 以上、Chrome などの WebGL2 が動くブラウザー。

```sh
node tools/serve.mjs
# → http://127.0.0.1:8150/ をブラウザーで開く
```

組み立ての手順（ビルド）はありません。three.js は `vendor/` に同梱しています。

## 操作

### かんたん（押すだけ・はじめはこちら）

使うのは **Space かマウスの左クリック** だけです（スマホは右下の「押す」）。画面の下にゲージが出ます。

| 遊び方 | やること | 使う場面 |
|---|---|---|
| ねらって押す | 針が金色に来たときに押す | 靴をそろえる・敷居とへりをまたぐ・手土産の向き・帰りの会釈 |
| ためてはなす | 押している間ゲージがのびる。金色ではなす。赤までいくと失敗（珍事） | お辞儀・座布団に進む・手土産を差し出す・お茶を飲む |
| くり返し押す | 押すたびにのびる。手を止めると戻る | しびれた足で立つ・こぼしたお茶を拭く |
| 言葉を選ぶ | 出てきた言葉をクリック（1〜3 のキーでも） | 名乗る・答える・立て直し |

押したあとに「見事」「よし」「あっ」「やりすぎ」などの大きな文字が出ます。失敗すると珍事（ごつん・あつっ など）が起きて、ずかんに集まります。

### こだわり（前の操作）

設定の「操作」を「こだわり」にすると、マウスとキーを使い分ける前の操作になります。

| 操作 | キー |
|---|---|
| お辞儀（長く押すほど深く） | Space |
| 物をつかむ・置く・渡す | マウスの左ボタンを押したまま動かして離す |
| 物を回す | Q / E（またはホイール） |
| 物を傾ける | Z / X（またはホイール） |
| 選ぶ（言葉・立て直し） | 1 / 2 / 3 |
| 歩く | W A S D |
| 座る・姿勢を保つ | F を押し続ける |
| 一時停止 | Esc |
| そのところからやり直す | R |

### スマホ

横向きにして遊びます。かんたん操作では、右下の大きな「押す」ボタンひとつで遊べます。こだわり操作では、その場面で使う操作だけが画面のボタンとして出ます（下の表）。

| 操作（こだわり） | 指で |
|---|---|
| 歩く | 左下のスティック |
| お辞儀・座る | 右下の丸いボタンを押している間 |
| 物をつかむ・置く・渡す | 物を指で押さえて動かし、離す |
| 物を回す・傾ける | ⟲ ⟳・「傾ける」「戻す」のボタン |
| 選ぶ | 出てきた言葉を押す |
| 一時停止 | 左上の ‖ |

設定で、字幕の大きさ・マウスの感度・操作の手助け（向きが合いやすい・こぼれにくい）・画質・音量を変えられます。

## 結果の見方

結果は4つに分けて出します。点を1つにまとめません。

| 軸 | 中身 |
|---|---|
| 成立 | 挨拶が最後まで成り立ったか |
| 所作 | 各ところの動きの正確さ |
| 配慮と立て直し | 失敗のあとに場をどう取り戻したか |
| 珍事 | 起きた珍しい出来事（ずかんに集まる。点には入れない） |

## 確かめ方

```sh
# 台帳（200項目と場面の対応）を作り直して検査する
node tools/build-items.mjs
node tools/validate-items.mjs

# 第一章を「押すだけ」で自動で最後まで遊ぶ（good＝金色で押す人／clumsy＝失敗と珍事の道）
node tools/play-bot-easy.mjs docs/screenshots-easy good

# こだわり操作で自動で最後まで遊び、画面写真を残す（サーバーを起動してから）
node tools/play-bot.mjs docs/screenshots

# 同じことを、スマホの画面（844×390）と指の操作だけで行う
node tools/play-bot-touch.mjs docs/screenshots-phone

# 人物の確認室を、パネルのボタンだけで動かして確かめる（画面写真と結果を docs/lab に残す）
node tools/lab-bot.mjs docs/lab
```

`play-bot.mjs` は `~/.dev-browser/node_modules` の Playwright と、インストール済みの Chrome を使います。

## 作法の扱い

ゲームの中の作法は「よく言われるやり方の一例」です。地域・家庭・流派で違います。正解は1つと言い切りません。出典を確かめたものと、確かめていないものは台帳で分けています（`docs/ledger.md`）。
