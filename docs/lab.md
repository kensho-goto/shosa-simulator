# 人物の確認室（lab.html）

ひとりの人物（と相手役）を、小さな和室と手土産の箱で、**実際に操作して**確かめる場所です。
本編の会話や儀式の進行より先に、「近くで見ても、動かしても、人に見えるか」を詰めるために作りました。

- 手元で開く：`npm start` → <http://127.0.0.1:8150/lab.html>（合言葉は聞かれません）
- 公開ページ：<https://kensho-goto.github.io/shosa-simulator/lab.html>（合言葉 いいんじゃ）
- パソコン向けです（右に操作パネルが出ます）。スマホでも開けますが、パネルが画面の多くを隠します。
- 短い動画：[`docs/lab/lab-demo.mp4`](lab/lab-demo.mp4)（69秒。歩く・止まる・お辞儀・持つ・置く・渡す・失敗と持ち直し）

## 操作

右のパネルのボタンか、キーで動かします。「操作する人」で本人と相手役を切り替えられます。

| 動作 | ボタン | キー | 何が起きるか |
|---|---|---|---|
| 待機 | 待機 | I | いまの動作を止め、視線を自由にする |
| 止まる | 止まる | S | いまの動作を、壊れない形で終える（歩きは減速して止まる、お辞儀は上体を戻す、持つ途中は手を戻す） |
| お辞儀 | お辞儀 | O | 手を前へ → 上体を下げる（30°。箱を持っているときは15°）→ 0.9秒止める → 戻す |
| 箱を持つ | 箱を持つ | G | 箱が遠ければ歩いて近づく → 向き直る → 箱を見る → 手が届くだけかがむ → 手を伸ばす → 触れたか確かめる → 握る → 持ち主になる → 5cm 持ち上げる → 運ぶ高さへ |
| 箱を置く | 台Aに置く／台Bに置く | H（台B） | 台の前へ歩く → 箱を台の5cm上へ → 下ろす → 箱の底が台に着いたか確かめる → 手を離す → 手を戻す → 上体を戻す |
| 渡す | 相手に渡す | T | 相手の前へ歩く → 差し出す → 相手が両手で持った瞬間に持ち主が移る → 手を離して下がり、軽くお辞儀 |
| 最初に戻す | 最初に戻す | R | 2人の位置、箱（台Aの上）、表情、視線、途中の動作をすべて最初に戻す |
| 見る | こちら／相手／箱／自由 | Q／E／B／X | 首と目が、その先を追う（動作の途中でも受け付ける） |
| 歩く | 部屋の中央／台Aの前／台Bの前／相手の前 | W（中央） | 向きを変えながら加速し、近づくと減速して止まる。床を押した場所へも歩く。ほかの人はよける |
| 視点 | 顔の正面／横顔／会話の距離／全身／部屋／手元 | 1〜6 | 顔の正面と横顔は約95cm、会話は約1.25m から写す。手元は両手を約55cm から写す |
| 照明 | 確かめ用（安定）／和室 | — | 確かめ用は正面からの安定した光。和室は障子の光・天井の明かり・畳の照り返し |
| 不器用さ | 自然／不器用／不器用＋大げさ | — | 不器用にすると、持って歩くうちに箱が傾き、気づいて止まり、持ち直す。相手役も気づいて箱を見る |
| 人物 | 一覧から選ぶ | — | 本人を、別の年齢・性別・服装の人に替える（下の「人物の替え方」） |
| 画質 | きれい／かるい | — | かるいは陰影の後処理を切り、画素を減らす |
| パネル | パネル | P | パネルを隠す・出す |

### 重なったときの決まり

| いまの動作 | 来た命令 | 結果 |
|---|---|---|
| どれでも | 止まる | 受ける |
| どれでも | 見る | 受ける（動作とは別の通り道） |
| 歩く | 歩く | 行き先を変える |
| 歩く | お辞儀 | いったん止まってから、お辞儀する |
| そのほかの動作の途中 | 別の動作 | 断る（「いまは〇〇の途中なので受け付けません」） |
| 箱を持っている | 箱を持つ | 断る |
| 箱を持っていない | 置く・渡す | 断る |
| 相手が箱を持っている | 箱を持つ | 断る |
| 相手が別の動作の途中 | 渡す | 断る |
| 手が箱に届かない | — | 手を戻し「手が届かない」と出す（手を箱へ吸い付けない） |

断ったときは、画面左下に赤い字で理由が出ます。

## 仕組み（作り直すときの手がかり）

- 入力と動作を分けています。ボタン・キー・床を押す → `src/lab/lab.js` の `run()` → `CharacterController.command()`（`src/lab/controller.js`）。本編の進行からも同じ命令で動かせます。
- 毎コマの順番：動作の受け持ち（手首の目標を決める）→ 人物の骨の計算（`src/actor.js`）→ 箱の位置（`src/lab/item.js`）。
- 箱の持ち主は必ず1人です（`Holdable.holder`）。持っている間は、**持ち主の実際の手首の位置から**箱の位置と傾きを決めます。手と箱が離れて見えることがありません。
- 受け渡しは `transfer(from, to)` だけで持ち主が移り、持ち主が `from` でないときは何もしません（2人が同時に持ち主になることがない）。

## 人物の替え方

`src/lab/people.js` の一覧に、人物素材（`assets/people/<名前>/`）と身長を書くと、パネルの一覧に出ます。
いま選べるのは、手元にある Rocketbox の4人です。

| 一覧の名前 | 素材 | 身長 |
|---|---|---|
| 30代の男性・紺の無地のスーツ（はじめの設定） | Business_Male_02 | 1.72m |
| 40代の女性・グレーのスーツ | Business_Female_03 | 1.58m |
| 20代の女性・ニット | Female_Adult_11 | 1.60m |
| 60代の男性・ジャケット | Male_Adult_03 | 1.70m |
| 相手役 | Female_Adult_11 | 1.60m |

年齢の見え方は素材の顔立ちで決まり、数字で年齢を変える仕組みはありません。顔立ち・髪型・服を細かく変えるには、その素材を足すことになります。

## 見た目の調整（この確認室を作りながら直したこと）

| どこ | 直したこと |
|---|---|
| 歩き | **歩くと体が床へ沈む誤りを直した。** 上下の揺れの計算で、人物の縮尺で割っていたため、歩き出しに肩が約1.1m 下がっていた（本編の歩きにも出ていた）。直したあとの肩の高さは 1.27〜1.35m |
| 歩き | 速さに合わせて歩幅と歩数を決め、足が床をすべらないようにした |
| 手 | 首と背の向き（見る先）を先に決め、そのあとで腕を合わせる順にした。前は、腕を合わせたあとで背を回していたため、箱を見ながら手を伸ばすと手が最大7cm ずれていた |
| 手 | 指を1本ずつ曲げる。何もしないときは人差し指から小指へ少しずつ深く曲がり、わずかに動く（人の手の自然な形） |
| 手 | 指をそろえる。お辞儀のときはそろえて伸ばし、親指を人差し指に寄せる |
| 手 | 箱へ手を伸ばす間は、手のひらを箱の側面へ向け、指をそろえて開く |
| 手 | 箱を持つと、手のひらを側面に当て、親指を箱の上に添え、指先を底の下へ回し込む（底より下に出た関節だけを内側へ曲げる） |
| 手 | 手の形の計算を軽くした（1人1コマあたり約0.09ミリ秒） |
| 前かがみ | 決まった角度ではなく、手が届くだけかがむ（毎コマ、実際の肩から箱までの距離で決める） |
| 箱を持つ | 体の向きに対して箱を運ぶ位置へ寄せる（向きを変えても箱が横に取り残されない） |
| 失敗 | 箱が傾くときは、上の手はそのままで下の手が下がる（箱の中心で回すと、上の手が届かなくなる） |
| 視線 | 何も見ていないときは、ときどき視線と頭をわずかに動かす。物を見続けるときはお辞儀でも視線を外さない |
| まぶた | まぶたを少しだけ下ろしておき、下を見るほど下げる（全開だと見開いて見えた） |
| 照明 | 和室の天井の明かりの影を止めた（点の光の影が硬く、鼻の下にくっきりした影が出た）。代わりに畳と壁の照り返しを足した |
| 足もと | 足もとに接地の影を置いた（浮いて見えないように） |
| ぶつかり | 歩くとき、ほかの人をよける（前は相手役の体を通り抜けていた） |
| 部屋 | 手前に縁側の床と壁をのばした（部屋の外の黒い空間が写っていた） |
| 視点 | パネルに隠れない左側の真ん中に、写すものが来るようにした |

## 確かめたこと

`node tools/lab-bot.mjs docs/lab`（サーバーを起動してから）で、パネルのボタンを押す操作だけで動かして確かめます。結果は [`docs/lab/lab-result.json`](lab/lab-result.json)、画面写真は `docs/lab/*.jpg`。

| 確かめたこと | 結果 |
|---|---|
| 歩く途中で「止まる」 | 止まる |
| 歩く途中のお辞儀 | 止まってからお辞儀する |
| お辞儀の途中に箱を持つ | 断る |
| 持っていないのに置く／持っているのに持つ／相手が持っている箱を持つ | どれも断る |
| 置いた箱の位置 | 台Bの上（箱の底の高さの差 1mm 未満） |
| 持っている間の、手と箱のずれ | 最大 0.5cm（手元の写真 `docs/lab/10b-hands-hold.jpg`） |
| 受け渡しの持ち主の移り方 | 本人 → 相手役の1回だけ。ずれは最大 0.1cm 未満 |
| 不器用＋大げさ | 箱が最大35°傾き、止まって持ち直してから着く。持ち直しの間のずれは最大 1.0cm |
| 最初に戻す | 2人の位置・箱・途中の動作が戻る |
| ページのエラー | なし |

画面の速さ（全身の視点で、歩いている8秒の平均と最低）：

| 照明 | 画質 | 平均 | 最低 |
|---|---|---|---|
| 確かめ用 | きれい | 60.0 コマ/秒 | 60.0 |
| 和室 | きれい | 60.0 コマ/秒 | 60.0 |
| 和室 | かるい | 60.0 コマ/秒 | 60.0 |

測った環境：Apple M4（8コアの描画）・メモリ 16GB・macOS 27.2、Chrome（Playwright・ANGLE Metal）、画面 1280×720・画面の倍率 1。画面の速さは画面の更新（60回/秒）が上限です。

本編も、この直しのあとに自動で最後まで遊べることを確かめました（パソコン・スマホとも完走、エラーなし）。

## まだ確かめていないこと

- 人が実際に操作した感想（自動の操作だけで確かめています）
- 本物のスマホでの確認室
- 画面の倍率が2（Retina）のときの画面の速さ
- 人物を替えたあとの、4人それぞれでの持つ・置く・渡すの通し（はじめの設定の男性だけで通しています）

## 残っていること

- 素材の上限：Rocketbox は2015年ごろの素材で、髪が板状に見える、肌の細かさが足りない、指が硬いなど、素材そのものの限界があります。動きと光で詰められるところは詰めました。
- 箱を持つとき、膝を曲げずに上体だけでかがむ（低い台では深い前かがみになる）
- 相手役が箱の傾きに気づく反応は、見る・心配の顔・顔を戻す、だけです

## UE5 と MetaHuman を先に検討した結果

公式の文書で確かめた結果、**このパソコンでは使えない**と判断し、three.js のまま進めました。

| 項目 | 公式の推奨 | このパソコン |
|---|---|---|
| メモリ | 32GB | 16GB |
| 描画 | nVIDIA RTX 3070 / AMD RX 6800 XT / Apple M2 Ultra、描画用メモリ 8GB | Apple M4（8コア） |
| ディスク | Unreal Engine 本体と MetaHuman の資料で数十〜100GB 以上 | 空き 約32GB |
| そのほか | Xcode が要る（Mac）・Epic のアカウントでのサインインが要る | Xcode なし |

- 推奨の環境：<https://dev.epicgames.com/documentation/metahuman/hardware-requirements>
- 5.6 から MetaHuman Creator が Unreal Engine に入った：<https://dev.epicgames.com/documentation/metahuman/metahuman-creator-in-unreal-engine>
- 2025年6月の使用許諾の変更（Unreal 以外のゲームでも使えるようになった）：<https://www.metahuman.com/en-US/license>、<https://www.cgchannel.com/2025/06/you-can-now-sell-metahumans-or-use-them-in-unity-or-godot/>

使う場合の流れ（推奨の環境を満たすパソコンが要る）：

1. 人がする：Epic Games のアカウントで、はじめてのサインインをする（<https://www.unrealengine.com/download>）
2. AI がする：Unreal Engine 5.6 以上を「MetaHuman Creator Core Data」付きで入れ、人物を作り、書き出す
3. このゲームへ持ってくるなら、書き出した人物をブラウザーで動く形に変える（重さの調整が要る）

ほかの道（費用がかかるので、選ぶときは相談）：Reallusion Character Creator 5 と Headshot（有料。いまの使用許諾では他のゲームエンジンへの書き出しも可）。
