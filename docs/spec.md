# ゲーム仕様（試作 v0.1）

## 1. どんなゲームか

- 完成形は、200 の所作（S001〜S200）を扱う **1本のゲーム** です。
- 写実寄りの 3D の場に入り、決められた役（招かれた人・訪問者・参拝者など）として動きます。
- 面白さの芯は「普通にふるまおうとして失敗し、それでも場を成り立たせる」ことです。失敗をきっかけに立て直しを選び、場の空気を取り戻します。
- 作法は「よく言われる一例」として出します。正解は1つとは言いません。台帳で、出典を確かめた記述と、地域や家庭による違いと、ゲームの誇張を分けています（`docs/ledger.md`）。

## 2. 作り方の判断（エンジン）

| 候補 | 判断 |
|---|---|
| Unreal Engine 5 | 依頼文の第一候補。この PC は空きが約 36GB で、Xcode がなく、入れられない。見送り |
| ブラウザーの 3D（three.js r170） | 採用。すぐ動かせて、URL を開くだけで遊べる |

ブラウザーの 3D で足りないところと、その対策は次のとおりです。

- **人物の写実さ**：写実の人物（Rocketbox、MIT）に替えたが、日本の家族に見えにくい。着物がない。表情は 8 つの形だけ、指は軽く曲げるだけ。本番では、日本人の顔の人物モデルとモーションキャプチャを入れる。必要なら UE5 などへ移す。
- **光の質**：PBR の素材、HDRI の環境光、陰影（GTAO）、影で近づけている。リアルタイムの大域照明はない。
- **布や液体**：お茶の液面・こぼれ・座布団の沈みは、簡易な計算で表している。

場面の流れ・判定・台帳はエンジンに頼らない作りなので、移しても使い回せます。

## 3. 共通の操作（全場面で同じ入力）

どの場面も、次の5つの操作を組み合わせて作ります（`src/ops.js`）。

| 操作 | 入力 | 判定するもの |
|---|---|---|
| お辞儀 `bow` | Space を押す長さで深さ | 深さ（会釈・敬礼・最敬礼の帯）、相手との間合い（同時・先・後）、頭がぶつかる、お辞儀の応酬 |
| 物の扱い `hand` | マウスでつかむ・動かす・離す。Q/E で回す、Z/X やホイールで傾ける | 向き（相手から読めるか）、両手か、置く場所、落とす、傾き（液体の量・こぼれ・熱さ） |
| 選ぶ `choose` | 1〜3 | 言葉の選び方、立て直しの選び方。時間切れも反応になる |
| 歩く `walk` | WASD（カメラの向き基準） | 足の置き場（敷居・畳のへり・座布団を踏む）、歩く順・位置 |
| 姿勢 `posture` | F を押し続ける | 正座の保持、しびれ、立ち上がり |

### かんたん操作（押すだけ・2026-11-28 から最初の設定）

上の5つの操作は「こだわり操作」として残し、最初の設定は **押すボタンひとつ**（Space・左クリック・スマホの「押す」）にしました。ゲージ（`hud.gauge`）と大きな判定の文字（`hud.stamp`）で見せます。

| 型 | 中身（`src/ops.js`） | 判定 |
|---|---|---|
| ねらって押す `tap` | 針が行き来する。押した位置で判定 | 見事（濃い金）・よし（金）・あっ（外れ）・時間切れ |
| ためてはなす `charge` | 押している間のびる。はなした位置で判定 | 見事・よし・あっ（足りない）・やりすぎ（赤。珍事につながる） |
| くり返し押す `mash` | 押すたびにのび、待つと減る | 1 まで届けば成功 |
| 選ぶ `choose` | 言葉をクリック（1〜3 でも） | こだわりと同じ |

- 歩く・座るは自動にした。またぐ所（敷居・へり）は「ねらって押す」、立つ（しびれ）は「くり返し押す」。
- 珍事が起きると、名前を大きく出して画面を揺らす。
- 場面ごとの対応：お辞儀＝ためる、靴＝ねらう（回っている靴）、手土産＝ねらう（向き）→選ぶ→ためる（差し出す）、お茶＝押している間飲む（金色でひと口・赤は熱い・質問が来たら「！」ですぐはなす）、拭く＝くり返し、結婚の意思＝話の切れ目をねらって選ぶ、帰り＝くり返して立つ→待つ→ためるお辞儀→押して外へ→ねらって会釈。

- 操作の手助け（設定）を入れると、向きが合いやすく、こぼれにくくなります。
- 各ところは「チェックポイント」です。R でそこからやり直せます。

### スマホ（横向きで遊ぶ）

スマホでは、同じ5つの操作を画面の指の操作に置きかえます（`src/touch.js`）。その場面で使う操作だけが、ボタンとして出ます。

| 操作 | スマホの入力 |
|---|---|
| お辞儀 `bow` | 右下の丸いボタン「お辞儀」「会釈」を押している長さで深さ |
| 物の扱い `hand` | 物を指で押さえて動かし、離すと置く。回すは ⟲ ⟳、傾けるは「傾ける」「戻す」のボタン（物を押さえたまま、別の指で押す） |
| 選ぶ `choose` | 出てきた言葉をそのまま押す |
| 歩く `walk` | 左下のスティック |
| 姿勢 `posture` | 右下の丸いボタン「正座」「立つ」を押し続ける |

- 縦向きのときは「横にしてください」と出します。「はじめる」を押すと、全画面・横向きにします（対応しているブラウザーだけ）。
- スマホでは画質「かるい」から始めます（設定で変えられます）。
- 左上の ‖ で一時停止します。

## 4. 失敗と立て直し

- 大きな失敗には、必ず **2〜3 の立て直し** を出します（例：手土産を落とす → 拾って詫びる／笑ってごまかす／相手の手を借りる）。
- 立て直しの選び方で「配慮と立て直し」の点が動きます。所作の点とは分けて数えます。
- 相手役（父・母・相手）は、気持ちの値（`story.npc`）を持ちます。失敗や立て直しに合わせて、うなずき・首をかしげる・ため息などで反応します。
- 場の空気（`mood`）は画面右上に出ます。

## 5. 珍事（ちんじ）

- 珍事は、珍しい失敗や偶然の出来事です（例：お辞儀の応酬が止まらない、相手が代わりに答える）。
- **点数とは別** に集めて、ずかん（`珍事ずかん`）に残します。場面Aには 26 種類あります。
- 珍事を集めても、所作の点は上がりません。

## 6. 結果

| 軸 | 計算 |
|---|---|
| 成立 | 全てのところを最後まで通ったか |
| 所作 | 各ところの技の値（0〜1）の平均を 100 点に換算し、秀・優・良・可・要練習に分ける |
| 配慮と立て直し | 立て直しの選び方と、相手への気づかいの合計 |
| 珍事 | その回に出た珍事の一覧 |

いちばん良い結果と、集めた珍事は、ブラウザーの中に保存します（`localStorage` の `shosa.v1`）。

## 7. 場面A　親への結婚挨拶（第一章・遊べる）

役：相手の実家を初めて訪ねる人。相手役は、相手・父・母。

| ところ | 中身 | 主な項目 |
|---|---|---|
| A1 玄関の挨拶 | 出迎えにお辞儀。近すぎると頭がぶつかる → 立て直し | S027 立礼 |
| A2 靴をそろえる | 脱いだ靴を向きをそろえて端に置く。相手の靴が手本。違うと母が直す | S017 |
| A3 部屋へ入る | 敷居・畳のへりを踏まずに歩く | S019・S020 |
| A4 名乗りと座礼 | 正座して名乗る。父の話をさえぎらない。座ったままのお辞儀 | S023・S026 |
| A5 座布団と手土産 | 膝で進んで座布団へ（立って踏むと珍事）。手土産を相手に正面を向けて渡す。落とすと立て直し3つ | S022・S025・S028 |
| A6 お茶 | 湯のみを口へ運び、傾けて飲む。こぼす・熱い・むせる。飲んでいる途中に質問が来る | S029（受ける側） |
| A7 結婚の申し出 | 父の言葉の間を待って切り出す。沈黙が続くと母が助ける。相手と合わせて深いお辞儀 | S026 |
| A8 帰り | しびれた足で立つ。玄関で見送りのお辞儀。歩いて出る | S024・S027・S030（見送られる側） |

場面全体が S001「親への結婚挨拶」です。

項目ごとの「操作できる」の確認は `data/implementation.json` にあります。

## 8. 場面B・場面C（まだ遊べない）

台帳と流れは決まっています（`data/scenarios.json`）。上の共通の操作で作ります。

- **場面B　名刺交換から着席まで**：受付で名乗る → 案内されて移動 → エレベーター → 応接室 → 名刺交換 → 名刺を並べる → 着席 → 本題の前の挨拶。
  - 新しく要るもの：オフィスの場、名刺の差し出し・受け取りの高さ比べ、上座・下座の判定。
- **場面C　神社参拝**：鳥居で一礼 → 参道の端を歩く → 手水 → 賽銭 → 鈴 → 二拝二拍手一拝 → 授与所（任意）→ 帰りの鳥居で一礼。
  - 新しく要るもの：境内の場、柄杓の手順、拍手のリズム判定。
  - 神社本庁の出典ページは確かめられていない（503）ので、記述は「未確認」のままです。

## 9. 画面と設定

- タイトル・場面えらび（ところから始められる）・珍事ずかん・設定・一時停止・結果。
- 文字を角丸の箱に入れず、映画の字幕のように画面へ重ねます。
- 設定：字幕の大きさ（小・中・大）、マウスの感度、操作の手助け、画質（きれい・かるい）、音量。

## 10. 決まり（依頼文から）

- 確かめていない作法を、正式・唯一の正解と書かない。
- 珍事集めと所作の点を混ぜない。
- 大きな失敗には 2〜3 の立て直しを出す。
- 人の試遊をしていないのに、したと書かない。
- 仮素材の段階と完成見本の段階を分けて報告する。
- 生成した絵をゲーム画面として見せない（`docs/screenshots/` は実際のゲーム画面だけ）。
